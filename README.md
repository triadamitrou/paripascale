# Pari Pascale

Mock-up four of the Pari Pascale website (Union of Love Coach). A single static page with no build step:
open `index.html`, or serve the folder with any static host.

- Home: five scrolling sections (welcome, about, the menu, the coaching journey, client stories)
- Subpages by link: `#about`, `#podcast`, `#blog`, `#prices`, `#contact`
- Booking: paste Pascale's Calendly address into `const CALENDLY = ''` in the script
- Anything in [square brackets] is waiting on Pascale's content
- The page carries `noindex` while it is a mock-up; remove that meta tag at launch
